## Mouse

| Action | How |
| --- | --- |
| Select a table cell or a column | <kbd>⌘</kbd>-click |
| Select several table cells | <kbd>⌘</kbd>-drag |
| Move a block | Drag the **⋮** handle |
| Close a tab | Middle-click the tab |
| Rename a document | Double-click its tab |
